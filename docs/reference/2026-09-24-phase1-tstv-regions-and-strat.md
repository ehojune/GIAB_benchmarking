- **v4.2.1 밖 SNP 는 5런 전부 DV 가 이긴다** (+0.028~0.032). recall 은 비슷하고(FN 차 700~2,900) **FP 가 절반**이다.

- **§1 의 ts/tv 순차분(DV 초과 8~18만 SNP, ts/tv −0.09~0.34) 은 판정 가능한 곳에 없다.** 답 층에서는 C3 가 오히려
  1.1~1.5만 개 더 부르고, chrX·Y 층은 같다. 즉 DV 초과분은 **v4.2.1 도 v5.0q 도 덮지 않는 구간**에 있다(Revio 기준
  약 19만 = 18.2만 + 1.1만). 거기엔 truth 가 없어 FP 라고 채점할 수 없다. transversion 쪽으로 치우친 ts/tv 가 그 구간의
  호출이 오류에 가깝다는 **간접** 신호로 남는다. (TP+FP 는 hap.py 의 truth 쪽 TP 와 query 쪽 FP 를 더한 근사치다.)
- chrX·Y 층 F1 0.06 은 ONT §4 와 같은 모양(FN≈FP) — HG002 남성 반접합 구간에 이배체 유전형을 낸 탓으로 보인다. caller 성능이 아니다.
