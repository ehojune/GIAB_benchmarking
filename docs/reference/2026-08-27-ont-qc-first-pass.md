## 확정된 것 세 가지

### 1. 리드 개수 기준 매핑률은 ONT 건강도 지표가 아니다

R9 8런의 `rd%`가 39.1~89.3으로 벌어졌지만 정렬 실패가 아니었다. 미매핑 리드가 짧다:

| dsid | 매핑 리드 평균 | 미매핑 평균 | 배수 |
|---|---|---|---|
| HG004 | 19,676 bp | 1,599 bp | **12.3x** |
| HG002.UCSC | 18,150 bp | 1,631 bp | **11.1x** |
| HG003 | 18,065 bp | 2,456 bp | 7.4x |
| HG005~007 | 28,331~29,003 bp | 10,832~12,365 bp | 2.3~2.7x |

짧은 fail/adapter 리드가 개수만 채우고 염기는 기여하지 않는다. 같은 런들의 염기 매핑률은
90.6~95.2%로 정상이고, SNP 수(4.25~4.47M)·ts/tv(1.86~1.92)·위상률(76~81%)이 `rd%`와
무관하게 일정하다. UCSC 2020-05-08 릴리스(HG002~004)가 fail 리드를 포함하고 Guppy 4.2.2
릴리스(HG005~007)는 pass만 담은 차이로 보인다.

**예외 — HG001(rel6)은 다르다.** 미매핑/매핑 길이비가 1.0(8,729 vs 8,438)이라 짧은 리드가
아니라 진짜 미매핑이다. 2016~17년 R9.4 구형 베이스콜이라 염기 매핑률도 최저(83.3%)다.
버그가 아니라 데이터 품질 차이다.

→ 판정을 염기 기준으로 옮기고 `rd%`는 표시 + 30% 트립와이어로만 쓴다. `unmapLen`을 상시
지표로 넣어 원인이 보이게 했다.

### 2. DeepVariant raw 카운트는 RefCall로 1.7~3.4배 부풀어 있다

`--pass-counts`가 이걸 정리한다. PASS만 세면 Clair3와 3~7% 안에서 일치한다.

| dsid | C3 raw→PASS | DV raw→PASS | PASS C3/DV 비 |
|---|---|---|---|
| HG008-N-D | 4.70M → 4.67M | 8.15M → 4.37M | 0.935 |
| HG008-N-P | 4.79M → 4.76M | 11.66M → 4.47M | 0.940 |
| HG008-T.NE-UL | 4.13M → 4.08M | 6.83M → 3.98M | 0.976 |
| HG008-T.UCSC-UL | 4.24M → 4.21M | 14.49M → 3.93M | 0.933 |
| HG008-T.UCSC-std | 4.08M → 4.05M | 8.94M → 3.88M | 0.958 |

Clair3는 raw↔PASS 차이가 1% 미만인데 DeepVariant는 절반 이상이 RefCall이다. phase1에서
확인된 것과 같은 함정이고, **caller 일치 판정을 `--pass-counts`에 묶어 둔 설계가 맞았다** —
raw로 판정했으면 5런 전부 "caller 불일치" 오탐이 났다.

### 3. R9 indel 정확도는 베이스콜러 버전이 지배한다

PASS indel 수 (사람 germline 기대치는 대략 500~600k):

| 베이스콜러 | 런 | PASS indel |
|---|---|---|
| guppy 4.2.2 | HG005, HG006, HG007 | 544~551k |
| guppy 3.4.5 | HG002.guppy-V3.4.5 | 710k |
| guppy 3.2.x | HG002.UCSC, HG003, HG004 | 1,751~1,969k |
| guppy rel6 (2019 재배포) | HG001 | 1,714k |

guppy 3.2.x → 4.2.2에서 **3.5배** 줄어든다. homopolymer indel FP가 베이스콜러 개선으로
사라진 것이다. ts/tv는 같은 축으로 움직이지 않으므로(1.86~1.97, 추세 없음) SNV FP는 대략
일정하고 indel만 베이스콜러에 민감하다.

→ **R9 indel 분석은 Guppy 4.2.2 데이터셋(HG005~007)에서만 신뢰할 만하다.** SNV는 전 런 사용 가능.

### 부수 확인: 메틸 태그는 보존됐다

uBAM 진입 5런 전부 `MM%` = 100 (표본 200 리드). `samtools fastq -T MM,ML | minimap2 -y`
경로가 의도대로 동작한다 — uBAM 진입을 고른 이유가 검증됐다.

## 열린 질문: ts/tv가 전 런 낮다

R9 1.86~1.97, R10 1.65~1.73. 사람 germline SNV의 ts/tv는 보통 2.0~2.1이라 **전 코호트가
낮다** = FP 과다 신호다. 두 가지가 얽혀 있어 여기서는 못 가른다.

- R10이 R9보다 **낮다**. 정확도로는 설명이 안 된다(R10 sup이 더 정확하다).
- R10 5런은 전부 HG008(췌장암 환자)이고 R9 8런은 HG001~007이다 — 케미스트리와 개인이 교락돼 있다.
  HG008-N-D/N-P는 정상 조직인데도 1.70~1.71이라 종양 특이 현상은 아니다.

이 값은 전장 유전체 전역 카운트이고 benchmark 영역 밖(반복서열 등)의 FP를 포함한다.
**truth set 대비 hap.py로만 판정할 수 있고 phase2에는 아직 그 단계가 없다** (phase1은
`60_benchmark.sh`). 그게 다음 작업이다.
